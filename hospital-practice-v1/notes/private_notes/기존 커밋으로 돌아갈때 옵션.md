# 기존 커밋(e041b9e)으로 되돌리기 옵션 정리

## 목표
- 작업 폴더를 **e041b9e 커밋 당시 상태**로 완전히 되돌린다.
- `U`(미추적 파일, Untracked)까지 정리해서 **Changes = 0** 상태를 만든다.

---

## 1) 커밋 시점으로 되돌리기 (추적 파일)
```bash
git reset --hard e041b9e


## 2) U 같은 미추적 파일까지 싹 정리하기 (진짜 “그때”로)
git clean -fd

완료 기준 (정상 체크)

✅ VS Code Source Control에서 Changes = 0

✅ 터미널에서 아래 결과가 나오면 정상

git status


기대 결과: working tree clean

주의사항

git reset --hard : 추적 파일 변경사항을 되돌림 (되돌리기 어려움)

git clean -fd : 미추적 파일을 삭제함 (되돌리기 어려움)

삭제가 불안하면 (선택: 임시 보관)
git stash push -u -m "WIP before reset"
